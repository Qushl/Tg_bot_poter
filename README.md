# Telegram-бот «Потеряшки УрФУ»

Telegram-бот для публикации и поиска потерянных и найденных вещей в корпусах,
кампусах и общежитиях УрФУ, а также в других местах Екатеринбурга.

## Возможности

- публикация объявления о потерянной или найденной вещи;
- обязательное фото, описание, город/район и контакт;
- выбор корпуса или площадки УрФУ;
- предварительный просмотр и подтверждение публикации;
- просмотр активных объявлений с пагинацией по 5 записей;
- фильтр по корпусу/кампусу УрФУ;
- дополнительный фильтр по городу или району;
- поиск по ключевым словам в заголовке, описании, городе и названии корпуса;
- защита от частой публикации и повторных одинаковых объявлений;
- автоматическое закрытие активных объявлений через 30 дней;
- просмотр собственных объявлений;
- закрытие объявления его владельцем;
- сообщение, если в выбранном месте объявлений пока нет.

Доступные площадки: ГУК, Электрофак, Стройфак, Теплофак, Радиофак,
Физтех, Третий учебный корпус, УПИШ, Куба, Новокольцовский, корпуса в
центре, общежития и спортивные корпуса УрФУ, а также «Другое место».

## Стек технологий

- **Python 3.11+** — основной язык проекта;
- **aiogram 3.x** — асинхронная работа с Telegram Bot API, роутеры и FSM;
- **SQLAlchemy 2.0 Async ORM** — модели и асинхронные запросы к базе;
- **SQLite** — локальная файловая база данных без отдельного сервера;
- **aiosqlite** — асинхронный драйвер SQLite;
- **python-dotenv** — загрузка `BOT_TOKEN` и `PROXY_URL` из `.env`;
- **aiohttp-socks** — подключение через необязательный SOCKS5/Shadowsocks-прокси;
- **unittest** — автоматическое тестирование базы, фильтров, пагинации и интерфейса.

## Установка

Проверьте версию Python:

```bash
python3 --version
```

Требуется Python 3.11 или новее. Затем из папки проекта выполните:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

При каждом новом открытии терминала активируйте окружение:

```bash
source .venv/bin/activate
```

## Настройка

Создайте `.env` из примера:

```bash
cp .env.example .env
```

Заполните `.env`:

```env
BOT_TOKEN=токен_от_BotFather
PROXY_URL=
```

`BOT_TOKEN` можно получить у [@BotFather](https://t.me/BotFather).

Если Telegram доступен напрямую или через системный VPN, оставьте
`PROXY_URL` пустым. Если требуется SOCKS5, укажите реальный адрес:

```env
PROXY_URL=socks5://user:password@host:port
```

Для локального Shadowsocks-клиента адрес может выглядеть так:

```env
PROXY_URL=socks5://127.0.0.1:1080
```

Он работает только тогда, когда локальный клиент запущен и слушает порт 1080.
Файлы `.env`, `.env.save` и другие локальные варианты `.env` исключены из Git,
чтобы токен не попал в репозиторий.

## Запуск

```bash
source .venv/bin/activate
python main.py
```

При успешном запуске появится сообщение:

```text
INFO:aiogram.dispatcher:Start polling
```

После этого откройте бота в Telegram и отправьте `/start`. Остановка — `Ctrl+C`.

## База данных

При первом запуске бот автоматически создаёт файл `lost_found.db` и таблицы:

- `users` — пользователи Telegram;
- `items` — объявления, фотографии, площадки, контакты и статусы.

Для создания новой пустой базы сначала остановите бота, затем выполните:

```bash
rm lost_found.db
python main.py
```

Внимание: удаление `lost_found.db` безвозвратно удаляет всех пользователей и
объявления.

## Тесты

Тесты используют встроенный модуль `unittest`, поэтому pytest не требуется.
Они проверяют:

- создание и чтение объявлений в SQLite;
- фильтрацию по кампусу и городу/району;
- поиск по нескольким ключевым словам, включая кириллицу;
- блокировку повторного одинакового объявления;
- пагинацию по 5 объявлений;
- закрытие объявления владельцем и запрет закрытия чужого объявления;
- обновление данных пользователя;
- обязательные кнопки меню и основные корпуса УрФУ;
- допустимую длину callback-кнопок Telegram;
- регистрацию обработчиков aiogram.

Запуск всех тестов:

```bash
source .venv/bin/activate
python -m unittest discover -s tests -v
```

Успешный результат заканчивается строкой `OK`. Быстрый запуск:

```bash
python -m unittest discover -s tests -q
```

Проверка зависимостей:

```bash
python -m pip check
```

## Структура проекта

```text
main.py          — запуск бота и подключение к Telegram
config.py        — загрузка BOT_TOKEN и PROXY_URL
database.py      — модели и автоматическое создание SQLite
repository.py    — запросы к базе данных
handlers.py      — команды, FSM, объявления и фильтры
keyboards.py     — меню, кампусы и inline-кнопки
states.py        — состояния FSM
tests/           — автоматические тесты
requirements.txt — зависимости Python
.env.example     — пример настроек
```
